# شرح شامل لـ Api Tokio في Rust


---

## نظرة عامة

**Tokio** هي بيئة تشغيل (Runtime) غير متزامنة لـ Rust، توفر الأدوات اللازمة لكتابة تطبيقات شبكية عالية الأداء. تتضمن المكتبة وحدات متعددة تغطي عمليات الملفات، الإدخال/الإخراج، الشبكات، إدارة العمليات، المزامنة، المهام، والتوقيت.

---

## 1. الهياكل (Structs)

الهياكل هي أنواع بيانات مركبة تحتوي على حقول متعددة وتُستخدم لتمثيل كيانات محددة في المكتبة.

### 1.1 وحدة نظام الملفات (`fs`)

| الهيكل | الشرح |
|--------|-------|
| `fs::DirBuilder` | يُستخدم لإنشاء مجلدات بخيارات مخصصة بشكل غير متزامن، مثل إنشاء المجلدات الأب تلقائياً |
| `fs::DirEntry` | يمثل إدخالاً واحداً في مجلد (ملف أو مجلد فرعي) يتم الحصول عليه أثناء قراءة محتويات مجلد |
| `fs::File` | يمثل ملفاً مفتوحاً للقراءة أو الكتابة بشكل غير متزامن |
| `fs::OpenOptions` | يوفر خيارات متقدمة لفتح الملفات (قراءة، كتابة، إنشاء، إلحاق) |
| `fs::ReadDir` | مُكرر (Iterator) غير متزامن يقرأ محتويات مجلد إدخالاً تلو الآخر |

## 4. الماكروهات (Macros)

الماكروهات هي أدوات توليد كود في وقت الترجمة تُبسط الأنماط الشائعة.

| الماكرو | الشرح |
|---------|-------|
| `join!` | ينتظر اكتمال عدة مستقبليات بشكل متزامن (concurrent) ويُرجع نتائجها جميعاً |
| `pin!` | يُثبت مستقبلاً على المكدس (stack pinning) ليمكن استخدامه مع `select!` |
| `select!` | ينتظر عدة مستقبليات وينفذ فرع أول مستقبل يكتمل |
| `task_local!` | يُعرِّف متغيراً محلياً للمهمة (مثل thread-local لكن على مستوى المهمة) |
| `try_join!` | مثل `join!` لكن يتوقف فوراً عند أول خطأ ويُرجع `Result` |

## ملخص

تُقدم مكتبة **Tokio** بنية تحتية شاملة للبرمجة غير المتزامنة في Rust، وتتضمن:

- **نظام ملفات غير متزامن** (`fs`) — عمليات الملفات والمجلدات
- **إدخال/إخراج غير متزامن** (`io`) — تيارات، مخازن مؤقتة، وأدوات نسخ
- **شبكات** (`net`) — TCP, UDP, Unix sockets, وأنابيب Windows المسماة
- **إدارة عمليات** (`process`) — تشغيل ومراقبة عمليات فرعية
- **بيئة تشغيل** (`runtime`) — تكوين وإدارة حلقة الأحداث والخيوط
- **إشارات** (`signal`) — الاستماع لإشارات النظام
- **مزامنة** (`sync`) — أقفال، قنوات، حواجز، وعدادات
- **مهام** (`task`) — توليد وإدارة المهام غير المتزامنة
- **توقيت** (`time`) — مؤقتات، مهل زمنية، وأدوات اختبار الوقت

هذه المكتبة هي الأساس الذي تُبنى عليه معظم تطبيقات Rust غير المتزامنة، بما فيها خوادم الويب، عملاء HTTP، وأنظمة قواعد البيانات.
